Prompt-injection testing for tool-using AI agents

Can a hidden instruction make your AI agent leak data?

Pick an attack, choose defenses, and watch the same agent run twice: once unprotected, once defended. Every tool call, policy violation and leaked secret is shown.

What runs here: a deterministic, deliberately gullible mock agent with simulated email, file and database tools. Nothing is sent anywhere and no real model is called. Results describe the harness and the defenses, not any commercial LLM.
