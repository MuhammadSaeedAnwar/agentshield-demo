Run a prompt injection attack on an AI agent

Pick an attack and some defenses. The same agent runs twice, once with no defenses and once with the ones you picked, and you see every tool call, rule it broke and secret it leaked.

Note: this uses a simple test agent that is easy to fool, with fake email, file and database tools. No real AI model is called and nothing is sent anywhere. The results show how the defenses behave, not how any commercial model behaves.
